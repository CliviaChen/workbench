# 孟菲斯皮肤 · 改造说明

> 设计语言：[`DESIGN.md`](../DESIGN.md)（`awesome-design-md-main/design-md/memphis` 的 Memphis 设计系统）
> 风格参照：`C:\Users\cbxss\Desktop\人工智能\memphis-landing`（同一套语言的荧光落地版）
> 验收图：[`../配图/孟菲斯-场景总览.png`](../配图/孟菲斯-场景总览.png)（深色） · [`../配图/孟菲斯-个人站.png`](../配图/孟菲斯-个人站.png)（浅色）

## 1. 一句话

原来那套「深蓝底 + 细描边 + 发光 + 毛玻璃 + 10px 圆角」的科技风全部停用，
换成孟菲斯的「实心大色块 + 2px 硬边 + 零模糊硬投影 + 点阵/锯齿几何 + 方角」。

**两套底色**（标题栏「外观」按钮：跟随系统 / 浅色 / 深色）：

| | 画布 | 面板 | 文字 | 硬边 / 投影 |
|---|---|---|---|---|
| 深色 | `#0e0c10` 近黑 | `#17131c` | 骨白 `#f7f2e7` | 骨白边 + 近黑/四色投影 |
| 浅色 | **Claude 风米黄 `#f5f0e6`** | `#fffcf5` | 墨黑 `#161513` | 墨黑边 + 墨黑/四色投影 |

四种荧光色（青柠 / 洋红 / 青 / 琥珀）两套主题共用；浅色下它们只当**填充色**，
不拿来当小字颜色（保证对比度）。

---

## 2. 为什么深色是荧光底、浅色是米黄底

- **深色**：跟参照项目（`memphis-landing`）一致，也是这套工作台原来的主场——几十个渲染器
  的既有颜色假设（浅字/深底）继续成立，改造成本最低；
- **浅色**：按需求做成 **Claude 风格的暖米黄**（`#f5f0e6`，不是纯白/冷白），
  对应 `DESIGN.md` 默认的骨白画布，同时避免纯白把荧光色衬得刺眼；
- 两套都是「实心平涂、2px 硬边、零模糊硬投影、方角」，只是画布/文字反相——
  `DESIGN.md` 的规则一条没破。

## 3. Token 映射（原变量 → 孟菲斯）

| 原变量 | 原值（科技风） | 新值（孟菲斯） | 用处 |
|---|---|---|---|
| `--bg` | `#0b0d12` | `#0e0c10` | 画布 |
| `--bg-panel` | `#131722` | `#17131c` | 面板 / 卡片 |
| `--bg-panel-hover` | `#1a2030` | `#221b2b` | 悬停 |
| `--border` | `#232a3a` | `rgba(247,242,231,.55)` | 硬边 |
| `--text` | `#e6e8ee` | `#f7f2e7`（骨白） | 正文 |
| `--text-dim` | `#8b93a7` | `#a29a8e` | 次要文字 |
| `--accent` | `#4f8cff` | `#c8ff00`（荧光青柠） | 主强调 |
| `--ok / --warn / --err` | 绿 / 黄 / 红 | `#7cffb2` / `#ff8a00` / `#ff2e9a` | 状态 |
| 新增 | — | `--mem-lime` `--mem-magenta` `--mem-cyan` `--mem-amber` `--mem-ink` `--mem-display`，以及 `--mem-canvas` `--mem-surface` `--mem-surface-2` `--mem-text` `--mem-text-dim` `--mem-line` `--mem-shadow` `--mem-dot`（**全部按深/浅两套主题各给一份值**） | 四色 + 墨黑 + 展示字体 + 主题化表面 |

> 浅色主题只换 `html[data-theme="light"]` 下这一组 `--mem-*` 的值，组件规则一行不用重写。
> 浅色：画布 `#f5f0e6`、面板 `#fffcf5`、标题/正文 `#161513`、边与投影 `#141413`。

字体：展示层 `Segoe UI Black / Arial Black`（Windows 自带，对应 DESIGN.md 的 Poppins/Futura 替身），
正文 `Inter / Segoe UI`。**不再用等宽字体**（`--mono` 也改成无衬线）。

## 5. 组件规则（皮肤层里怎么落的）

- **标题栏**：画布色底 + 2px 硬边 + 一条青柠/洋红虚线色带；品牌点改成旋转 8° 的洋红方块。
- **场景栏**：2px 硬边 + 底部**锯齿条**（内联 SVG，33px 一格）；选中标签 = 青柠实心块 + ink 描边 + 3px 硬投影。
- **面板**：2px 硬边 + 6px 硬投影，投影色按 `4n+1/2/3/4` 轮换青柠/青/洋红/琥珀；悬停抬起 2px、投影加到 9px。
- **面板标题栏**：左侧 6px 色条（同轮换），标题用展示字体、字重 800。
- **控件**：小按钮统一「亮色实心卡 + ink 边 + 3px 硬投影」；悬停抬起、按下压平（DESIGN.md 的标准交互对）。
- **输入框**：2px 硬边、2px 圆角，聚焦时 3px 青柠 ring。
- **浮层**：模态标题栏青柠底 ink 字；主题菜单 8px 硬投影；启动页实底 + 点阵 + 青柠进度条。
- **顶栏弹层**（右上「文件夹」「⋯」和外观菜单）：原实现把底色写死成 `#12161f`、10px 圆角、软阴影，
  浅色主题下就是「深底 + 深字」看不见；现在整套 token 化——实底、2px 硬边、8px 硬投影、方角，
  行悬停青柠实心，磁盘条 / 按钮 / 输入框 / 体检明细也一起换（`memphis.css` 第 11 节）。
- **外观菜单位置**：外观按钮被收进 ⋯ 菜单后是隐藏状态（rect=0），原来会把菜单甩到屏幕左边；
  现在检测到隐藏就固定贴右上角。
- **圆角纪律**：面板内容里所有矩形统一收到 2px（原 8~16px 全部覆盖），圆形元素（头像/圆点/药丸）保留整圆。
- **个人站场景**：卡片白色实心块 + ink 边 + ink 硬投影，图标块洋红/青，状态药丸青柠。
- **浅色主题**：上列规则全部走 `--mem-*` 变量，`html[data-theme="light"]` 只换一组 token——
  画布 `#f5f0e6`、面板 `#fffcf5`、文字 `#161513`、边/投影 `#141413`。

## 6. 已知边界（没有硬套的地方）

1. **引擎 webview 内部已经换装（2026-11-23 补）**：早期版本管不到 DSH 自己的界面，现在通过 `MEMPHIS_ENGINE_CSS`
   覆盖它的设计变量（`--dsw-alias-*` / 圆角 / 阴影）并加少量容器规则，浅深两套都跟壳同步。
   ⚠ 仍有少数 DSH 组件是硬编码颜色、不读变量（例如个别插画/图表），这些地方会保留它原样。
2. **数据可视化保留功能色**：磁盘占用环、行情图等按 `DESIGN.md` 的《Known Gaps》视为独立系统，
   只统一外框与字体，不强行套四色（否则红/绿语义会丢）。
3. **顶栏图标 / 标签栏图标仍是原图**：它们是 PNG/SVG 资源，没有重绘。
4. **跟随系统依赖 Windows 的「应用模式」设置**：系统切深浅色后界面会实时跟着换（监听 `prefers-color-scheme`）；
   也可以随时在标题栏「外观」里手动锁成浅色/深色。

## 8. 内嵌 DSH 界面（对话页）也换装

DSH 是独立打包的前端（`app.asar`），样式全走它自己的 CSS 变量。皮肤层不去改它的代码，
只在每个引擎 webview 里注入一份 `MEMPHIS_ENGINE_CSS`（[main.js](外壳/main.js)）：

- 覆盖 `--dsw-alias-bg-* / label-* / border-* / button-* / state-* / scrollbar-*`、圆角（`--dsw-radius-*` → 2px）、
  阴影（`--dsw-shadow-lv1/2/3` → 零模糊硬投影）；
- 容器级补丁：正文底、`[data-composer-card]`（2px 硬边 + 3px 硬投影 + 方角）、代码块、侧栏分隔线；
- 两套主题：`html[data-mem-theme="light"]`（Claude 米黄）/ `dark`（暗底荧光），由壳的主题按钮联动；
- 注入时机：`dom-ready` 自动补投（页面重载也不会丢），渲染层切主题/开关时再同步一次。

## 9. 孟菲斯开关

标题栏有一枚方形拨动开关「孟菲斯」（`#btn-memphis`，在 🌙 左边）：

- **开**：加载 `memphis.css`，壳 + 内嵌 DSH + 顶栏弹层全套孟菲斯；
- **关**：`<link disabled>` + 引擎属性置 `off` ⇒ 回到原来的深色科技风（同时把外观锁成深色、隐藏 🌙，因为旧浅色规则已停用）；
- 状态存 `localStorage.guiMemphis`，重启保持；关掉时开关本身用 `styles.css` 里的兜底样式，仍然可见可点回来。
- 实现：`renderer.js` 的 `initMemphisToggle / applyMemphis`；引擎侧由 `main.js` 的 `skin:apply` 广播到所有引擎 webview。
