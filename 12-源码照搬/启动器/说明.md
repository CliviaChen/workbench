# 启动器

双击 **`启动工作台.vbs`** 就是启动「正能量阿陈的工作台」；桌面上那个孟菲斯图标的快捷方式指向的也是它。

## 里面有什么

| 文件 | 干什么 |
|---|---|
| `启动工作台.vbs` | 启动器本体（无控制台窗口）。检查依赖 → 判断是否已在运行 → 设好环境变量 → 拉起 Electron |
| `创建桌面快捷方式.ps1` | 重新生成桌面快捷方式（换了图标、搬了目录之后跑一次） |
| `素材\工作台-孟菲斯.ico` | 孟菲斯图标（16/24/32/48/64/128/256 七档，Windows 按尺寸自动选） |
| `素材\工作台-孟菲斯-512.png` | 图标大图（文档/分享用） |
| `素材\尺寸预览.png` | 各尺寸可读性预览 |
| `素材\原图标备份\` | 换肤前 `外壳\icon.ico` / `icon.png` 的备份 |

## 启动器会做什么

1. **依赖检查**：缺 `外壳\node_modules\electron\dist\electron.exe` 或 `引擎\apps\cli\lib\bin.js` 时弹窗说清缺什么、怎么补；
2. **防重复启动**：3080 已经有响应就**不再开第二个**，直接把你已经开着的窗口切到前台；
3. **环境变量**：`DSH_PORT=3080`、`DSH_HOME` / `DSH_CUSTOMER_HOME` 指向 `引擎数据\.dsh`、`DSH_SHELL_DIR` 指向 `外壳`；
   并**清掉**从 DSH 终端继承的 `ELECTRON_RUN_AS_NODE`（不清掉 Electron 会按 Node 模式秒退）；
4. **拉起**：以 `外壳` 为工作目录启动 Electron，窗口正常显示。

## 命令行自检

```powershell
cscript //nologo 启动工作台.vbs --check
# 输出：root=…  electron=True  engine-shim=True  port3080=False
```

## 重建桌面快捷方式

```powershell
powershell -ExecutionPolicy Bypass -File 创建桌面快捷方式.ps1            # 只建桌面
powershell -ExecutionPolicy Bypass -File 创建桌面快捷方式.ps1 -StartMenu  # 同时建到开始菜单
```

> 图标缓存没刷新的话：桌面按 F5，或注销/重新登录一次。

## 换图标 / 换名字

- 换图标：替换 `素材\工作台-孟菲斯.ico`，再跑一次 `创建桌面快捷方式.ps1`（快捷方式的 `IconLocation` 指的就是这个文件）。
- 换名字：跑脚本时加 `-Name "你的名字"`，或在快捷方式属性里改。
