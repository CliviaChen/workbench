# 记忆神经元面板：它到底是什么

> 位置：「命令」场景左半边那块大画布（面板标题「记忆神经元」）。
> 一句话：**它把这套工作台的"记忆系统"画成一张关系网**——点 = 一条记忆/一个场景/一个技能/一个项目，线 = 它们之间的归属与引用。
> 它**不是文件管理器**，也不是磁盘目录树；之所以看起来像文件结构，是因为这套记忆本来就存在一堆 Markdown/JSON 文件里。

## 1. 图上每个点是什么

| 点（节点） | 来自哪里 | 含义 |
|---|---|---|
| 中心「DSH 记忆」 | — | 整张网的根 |
| 待办 / 通知 / 冲突 | `_待办.md`、`_跨场景通知.md`、`冲突.md` | 跨场景共享的三份即时文档 |
| 场景区域（area） | `_共享记忆\索引.json` 的 `areas[]` + `areas\*.md` | 每个工作台场景（DSH·GUI改造、B站、命令…）一条记忆区域 |
| 私有记忆（§开头） | `_共享记忆\记忆地图.json` 的 `privateMemory[]` | 某个场景自己的私有记忆文件，只挂回它的场景 |
| 技能 | `.dsh\skills\*\SKILL.md` + `skills\_索引.md` | 技能包，线连到它的 owner 场景（没有归属就挂中心） |
| 项目 | `_共享记忆\项目.json`（没有就列项目根目录） | 被登记的项目工程 |
| 数据源 | `记忆地图.json` 的 `dataSources` | 工具/插件/MCP/会话档案/备份/台账/体检这些"家底" |
| 提交链（链 N） | `_共享记忆\提交链\*.jsonl` | 每个场景的提交锚点流水，点开能看到最近 3 段 |

## 2. 连线是什么意思

| 线 | 含义 |
|---|---|
| 内核 → 区域 / 数据源 / 共享文档 | 从属 |
| 区域 → 私有记忆 / 技能 / 提交链 | 归属（这条记忆/技能/链属于该场景） |
| 项目 → 区域 | 项目 owner（登记表给的，或正文里提到项目名的启发式） |
| 区域 ↔ 区域 | 一个场景的正文里提到了另一个场景（文本启发式「互相提及」） |
| 青色细线 / 灰细线 | **文件夹模式**才有：文件引用 / 目录包含（见下） |

## 3. 能怎么玩

- 拖拽旋转、滚轮缩放；
- 悬停某点：它的邻居亮起、其它变暗；
- 点某个点：右下角详情卡（路径、大小、归属、关系清单），可以「📂 打开」「🗂 资源管理器定位」「⧉ 复制路径」；
- 搜索框：按场景/技能/文件名/路径过滤（命中的点保持高亮）；
- 按钮：`⟳ 自转`、`⤾ 复位`、`只看记忆`、`动效：开/关`、`标签：自动/全部/关`、`↻ 重读`；
- 头部小字：当前数据源（共享记忆 · 只读）+ 统计 chips（区域/技能/私有记忆/数据源/连线/孤立/路径失效）。

## 4. 文件夹模式（2026-11-23 新增）

点 `📁 文件夹…` → 选任意一个目录 → 画布改成显示**这个目录自己的**目录/文件关系图：

- **点是**：根目录（中心，琥珀色）、子文件夹（琥珀色）、文件（按类型着色：Markdown 青柠、代码 青、数据/配置 品红、图片/媒体 骨白、其它 灰）；
- **线是**：`目录包含`（细灰线，父目录 → 子项）+ `文件引用`（青色线：Markdown 里的 `[](…)` / `[[wiki]]`、JS/TS 的 `import`/`require`、CSS 的 `url()`、HTML 的 `src`/`href`）；
- **布局**：按深度一圈圈往外，扇区按子树大小分配；节点多时自动缩小到能看全，标签默认「自动」（目录 + 悬停/选中/搜索命中的点才显示，避免上百个文件糊成一片）；
- **层级（单选，第二行「层级」）**：`2 层 / 3 层 / 4 层 / 全部` 四选一——根 = 0 层，选「2 层」就只画到第 2 层，深层的点整枝折掉（头部写「折叠 N 文件 / M 目录」）。第一次打开大目录（>250 点给 2 层、>120 点给 3 层）会自动选一个不糊的档位，之后记住你的选择；
- **只看文件夹（可与层级叠加）**：打开后只画根目录下的文件夹（文件全部折叠，引用线自然为 0），适合先看"目录骨架"再逐层展开；它和层级是**两个独立开关**，可以「3 层 + 只看文件夹」这样组合；
- **防糊**：点多时点径自动缩小（文件最小 2.1px、文件夹最小 4px），可见点 >200 时自动省掉引用线（头部写「引用线省 N」），只保留目录树；
- **切换**：`↩ 回到记忆` 回到原来的共享记忆网络；`↻ 重读` 重扫当前文件夹（层级/只看文件夹的选择会保留）；
- **记忆**：上次打开的文件夹会按面板记住（`localStorage` 的 `kneuFolder:<面板id>`），下次进场景自动恢复；路径失效时点 `↩ 回到记忆` 即可；
- **只读**：只 `stat`/`readFile`，不写、不改、不删任何文件；
- **限制**（防止选到 `C:\` 卡死）：最多 420 个节点、5 层深、最多读 220 个文件、单文件 ≤ 512KB、引用边 ≤ 900 条；跳过 `node_modules`、`.git`、`dist`、`build`、`.venv`、`发布` 等目录和隐藏文件；超出会在头部标「⚠ 节点过多已截断」。

> 数据接口在 `外壳\main.js`：`neuron:pick-folder`（原生选目录）和 `neuron:scan-folder`（扫成 `{nodes, edges, stats}`）；
> 画图在 `外壳\renderer\renderers.js` 的 `renderers.neuron`：`layoutFolder()` + `loadFolder()`。

## 5. 一句话区别

- **记忆模式**（默认）：回答"这套工作台记住了什么、谁和谁有关系"；
- **文件夹模式**：回答"我选的这个目录里有什么、哪些文件互相引用"。

两者共用同一套交互和视觉语言，只是数据源不同。
